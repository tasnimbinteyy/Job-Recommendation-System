SLIDE 3 — RELATED WORK & COMPARISON
================================================================

Title: Related Work — Existing Job Recommendation Systems

LinkedIn:
  - Proprietary ML engine — profile completeness,
    connection network, skill endorsements
  - Opaque algorithm, enterprise-grade
  - No explicit match score shown to users
  - Not accessible for academic replication [1]

Indeed:
  - Collaborative Filtering + keyword matching
  - Uses behavioral signals (click-through rates,
    application completions)
  - No skill gap feedback or resume scoring [2]

Glassdoor:
  - Focuses on company reviews and salary data
  - No algorithmic job-candidate matching [3]

BDJobs.com (Bangladesh):
  - Basic keyword search + category filtering only
  - Zero AI-based matching capability
  - Represents current state of local BD market

Table 2.1 — Platform Comparison

  Platform     | AI Matching          | Skill Gap | Resume Score | Open API
  -------------|----------------------|-----------|--------------|----------
  LinkedIn     | Proprietary ML       |    No     |     No       |   No
  Indeed       | Collaborative Filter |    No     |     No       |   No
  Glassdoor    | None                 |    No     |     No       |   No
  BDJobs       | Keyword Only         |    No     |     No       |   No
  This System  | Cosine Similarity    |    Yes    |     Yes      |   Yes (REST)

Research Gap Identified:
  - No existing platform provides transparent match scores
  - No open, reproducible AI matching for academic use
  - No locally-focused AI platform for Bangladesh tech market
  - This system addresses all three gaps

SLIDE 7 — AI ALGORITHMS
================================================================

Title: AI Algorithms

1. Cosine Similarity — Job Matching

   matchScore = ( |A ∩ B| / √(|A| × |B|) ) × 100

   Example:
     Candidate skills : {React, TypeScript, Node.js}           |A| = 3
     Job requirements : {React, TypeScript, PostgreSQL, Docker} |B| = 4
     Common skills    : {React, TypeScript}                    |A∩B| = 2

     matchScore = (2 / √12) × 100 = 57.7%

2. Skill Gap Analysis
     gap = Job Skills − Candidate Skills = {PostgreSQL, Docker}

3. Resume Scoring (0–100)

   Component     | Points | Criteria
   --------------|--------|------------------------------
   Skill Count   |   40   | Number of relevant skills
   Market Demand |   40   | Demand in current job postings
   Experience    |   20   | Experience section filled

SLIDE 9 — DATABASE DESIGN
================================================================

Title: Database Design

Tables:

  Table                | Key Relationships
  ---------------------|-------------------------------------
  User                 | Has many Applications, Jobs, Notifications
  Job                  | Belongs to User (Employer)
  Application          | User + Job (unique pair), stores matchScore
  Skill                | Master skills library
  Notification         | Belongs to User
  SavedJob             | User + Job (unique pair)
  NewsletterSubscriber | Email only

Normalization:
  - 1NF: Atomic values, primary key in every table
  - 2NF: No partial dependencies
  - 3NF: No transitive dependencies

SLIDE 10 — ROLE-BASED ACCESS CONTROL
================================================================

Title: Role-Based Access Control (RBAC)

Three User Roles:

  Role     | Dashboard  | Key Access
  ---------|------------|----------------------------------
  STUDENT  | /overview  | Browse, Apply, Resume Score
  EMPLOYER | /jobs      | Post Jobs, View Applicants
  ADMIN    | /admin     | Manage All Users, Jobs, Skills

Route Protection (Middleware):
  /admin/*     → ADMIN only
  /overview/*  → Authenticated + Onboarded
  /profile/*   → Authenticated + Onboarded
  /onboarding  → Authenticated + NOT yet Onboarded

Onboarding Flow:
  Sign In → Select Role → Save to DB → Redirect to Dashboard

SLIDE 13 — CHALLENGES, FUTURE WORK & CONCLUSION
================================================================

Title: Challenges, Future Work & Conclusion

Challenges Faced:
  1. Next.js App Router — steep learning curve for new server/client patterns
  2. JWT Session Refresh — token did not update after role change in onboarding
  3. TypeScript Type Conflicts — union types caused errors in applications page
  4. Adzuna API — no job listings available for Bangladesh
  5. PDF Parsing — only works for text-based PDFs, not scanned images

Future Work:

  1. Semantic Skill Matching — use Word2Vec so "React" and "ReactJS"
     are recognized as the same skill, improving match accuracy.

  2. Full 3NF Normalization — move skills from text arrays into
     a proper junction table to eliminate redundancy.

  3. Real-Time Notifications — replace polling with WebSocket
     or SSE for instant alerts without page refresh.

  4. Bangladesh Job Listings — integrate BDJobs.com once a
     public API becomes available.

  5. Mobile App — React Native app using the same backend API.

Conclusion:
  This project delivered a full-stack AI job recommendation platform
  with Cosine Similarity matching, Skill Gap Analysis, and Resume
  Scoring — supporting three user roles and live job integration.
  Built entirely on free-tier infrastructure with no paid AI APIs,
  it proves that meaningful AI-driven recommendations are accessible
  to all.
